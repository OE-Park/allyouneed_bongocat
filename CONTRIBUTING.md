# Contributing

## Commit messages

Write commit messages in English by default.

- Use a concise imperative subject, such as `Add Windows build workflow`.
- Keep the subject focused on one logical change.
- Add a body when the reason or tradeoff is not clear from the subject.
- Reference related issues in the body when applicable.

## Pull requests

- Keep each pull request focused on one purpose.
- Complete the pull request template and describe how the change was validated.
- Wait for all required CI, security, and review checks before squash merging.
- Add or update tests when behavior changes.
