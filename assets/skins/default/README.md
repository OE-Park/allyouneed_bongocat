# 기본 스킨
- 필요한 파일: `skin.json`, `cat-rest.png`, `cat-left.png`, `cat-right.png` (투명 PNG)
- 형식: docs/SPEC.md 6장
- 기본 이미지는 200×126 크기로 제작한다.
- 이 디렉터리는 권리 상태가 확인되지 않은 이미지를 포함하지 않는다. 자체 제작 자산이나 재배포가 명시적으로 허용된 자산만 추가하고 출처·라이선스를 함께 기록한다.
- 원본(luinbytes/bongocat) 이미지는 LICENSE 파일과 재배포 권한을 확인하기 전까지 사용하지 않는다.
